## О проекте

**Цифровой правозащитник** — веб-приложение, которое помогает гражданам России самостоятельно составлять юридически грамотные документы в двух категориях споров:

- **Возврат некачественного товара** — претензии и иски к продавцам на основании Закона РФ «О защите прав потребителей»
- **Споры с ЖКХ** — претензии и иски к управляющим компаниям и ТСЖ на основании ЖК РФ и ПП РФ № 354

Пользователь заполняет форму с данными о ситуации, отмечает имеющиеся доказательства — и получает готовый документ, сформированный языковой моделью с применением RAG (Retrieval-Augmented Generation).

## Архитектура

```
┌─────────────────────────────────────────────┐
│               Streamlit UI                  │
│  Форма → категория, тип документа, данные   │
└────────────────────┬────────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────────┐
│              RAG Engine                     │
│  1. Роутер (категория + тип чанка)          │
│  2. FAISS-поиск по базе знаний              │
│  3. Сборка промпта с контекстом             │
└────────────────────┬────────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────────┐
│         LLM (OpenAI-совместимый API)        │
│  T-Pro 2.0 / vLLM / HuggingFace TGI        │
│  → Готовый документ                         │
└─────────────────────────────────────────────┘
```

**Ключевые компоненты:**

- `app.py` — Streamlit-приложение: UI, формы, вызов модели
- `build_chunks.py` — парсинг базы знаний из `.docx` в JSON-чанки
- `build_index.py` — построение FAISS-индекса на основе `sentence-transformers`
- `test_retrieval.py` — тестирование RAG-поиска с примерами запросов
- `kb_chunks.json` / `kb_meta.json` — база знаний: шаблоны документов, нормы закона, доказательства

## Быстрый старт

### 1. Клонировать репозиторий

```bash
git clone https://github.com/your-org/digital-rights-defender.git
cd digital-rights-defender
```

### 2. Установить зависимости

```bash
pip install -r requirements.txt
```

<details>
<summary>Минимальный <code>requirements.txt</code></summary>

```
streamlit>=1.32
requests
faiss-cpu
numpy
sentence-transformers
python-docx
```

</details>

### 3. Подготовить базу знаний

Положите файл `rag_knowledge_base.docx` в папку `data/` и выполните:

```bash
python build_chunks.py   # парсинг docx → kb_chunks.json
python build_index.py    # построение FAISS-индекса
```

### 4. Запустить приложение

```bash
streamlit run app.py
```

Откройте [http://localhost:8501](http://localhost:8501) в браузере.

## Как работает RAG

1. **Роутинг** — по ключевым словам в запросе определяется категория спора и тип нужного чанка (шаблон претензии, доказательства, нормы закона и т.д.)
2. **Retrieval** — FAISS-поиск по косинусному сходству в пространстве эмбеддингов (`paraphrase-multilingual-MiniLM-L12-v2`)
3. **Augmentation** — релевантные чанки из базы знаний вставляются в промпт вместе с данными пользователя
4. **Generation** — LLM генерирует итоговый документ строго по структуре шаблона

### Структура базы знаний

| Раздел | Категория | Содержание |
|---|---|---|
| 1.1–1.6 | `return_goods` | Нормы ЗоЗПП, классификация требований, алгоритм, доказательства, шаблоны |
| 2.1–2.6 | `housing_utilities` | Нормы ЖК РФ + ПП 354, типичные нарушения, алгоритм, доказательства, шаблоны |
| 3.1–3.3 | `meta` | Правила генерации, различия категорий, ограничения модели |

## Тестирование поиска

```bash
python test_retrieval.py
```

Скрипт прогоняет 5 тестовых запросов и выводит топ-4 найденных чанка с оценкой релевантности:

```
Запрос: какие доказательства нужны для возврата испорченного товара
[1] score=0.8921  →  1.4_evidence | return_goods | evidence
[2] score=0.7643  →  1.5_pretrial_claim_template | return_goods | ...
...
```

## Что умеет сервис

- Генерирует **досудебные претензии** и **исковые заявления** на русском языке
- Подставляет данные пользователя в шаблоны со ссылками на конкретные статьи законов
- Показывает чеклист доказательств (обязательные / желательные) с предупреждением при неполном наборе
- Позволяет скачать готовый документ в формате `.txt`
- Отображает итоговый промпт для отладки

## Ограничения

> ⚠️ Документы носят **информационный характер** и не заменяют полноценную юридическую консультацию.

Сервис **не генерирует** документы по уголовным делам и делам с суммой иска свыше 1 млн руб. — в таких случаях рекомендуется обратиться к профессиональному юристу.
